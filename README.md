# DataVisFinal
## Overview
The dataset used was Top 1000 Most Popular Spotify Songs from Kaggle. URL here: "https://www.kaggle.com/datasets/kunalgp/top-1000-most-played-spotify-songs-of-all-time/data".
The dataset includes artist name, track name, album name, release date, and popularity (a score from 0-100 based on how many times the track was streamed. 100 being the most popular.)
My goal with this dataset was to find the top 5 artists with the most songs on the list, as well as exploring the impact of release month and duration on popularity. To achieve these goals I set myself the tasks of creating a frequency graph for song duration and comparing popularity between duration. I also set myself the task of creating a top 5 artists by song number graph along with a graph of all of the songs by the top 5 artists distributed over release date. My final task was to explore trends in release month and popularity by graphing the distribution of songs across their release month.

## Summary of  Design Elements and Discussion of Approach
I went into this visualization with the key elements being focused on clarity and conciseness. I wanted to create clean graphs that could quickly present main ideas but also have a bit of depth to them. I started this project by cleaning the data and doing some preliminary data exploration. I started by removing rows with a release data of January 1st as that seemed to be a placeholder date for songs where the exact release date was unknown. I also removed rows with a popularity score of 0 as that would not make any sense for a Top 1000 Songs list. After this I began looking for basic trends via rudimentary data exploration. From this I made the decision to look at top artists by song count, month release date and frequency, and the relation between song duration and popularity. For the graph of the Top 5 Artists by song count I went with a bar graph as this is a straightforward graph type that excels at presenting data on a small amount of quantitative variables which is exactly what this is. To compliment this graph I created a scatter plot of each song by the Top 5 Artist of its release year vs its popularity. Each artist is represented by a different color. On the full deployment a tooltip was implemented to show the track name, album name, and release date upon hovering a point and a point or a name on the legend can be clicked to filter for that artist. I believe these elements allow for a more indepth study of each artist by filtering out the others. A bar plot was made to show the frequency of songs released in every month. This is a simple but effective visualization to show any trends in the amount of songs released each month. To further expand on this a box plot of the popularity of the songs released in each month was made. I chose a box plot because I believed it would be the cleanest way to show all 12 months on one graph while giving a good overview of the popularity distribution in each month. Next I made a bar graph of the amount of songs released each year. I cut the domain off at 1990 because very few songs on the top 1000 were before this year (honestly could've cut the domain off at 2000 without losing much significance.) 2024 had by far the largest number of songs and goes agains the general trend of the graph. I wanted to expand on this so I created a scatterplot of the popularity of each song released in 2024 by month. I tried a boxplot as well to see how it would look but decided against as some of the months just did not have enough songs to get a good looking boxplot. I finished with a frequency histogram of the duration in minutes of each song as well as a box plot of the popularity and duration of the tracks. I wanted the box plot to show more depth on the relationship between popularity and duration but ran into some problems with it. I had to min the duration axis to create a cleaner graph but due to this binning the whiskers of the boxplot are misaligned with the boxes. I kept the boxplot in despite this because I think it can still be used to gain insight although it looks a bit strange. I think if I were to continue working on this project I could fix this problem by manually binning the data but I ran out of time for this assignment.
